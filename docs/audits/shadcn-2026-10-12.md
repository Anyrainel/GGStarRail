# Tailwind 4 shadcn refresh — 2026-10-12

Card was subsequently customized for section spacing and article composition;
see [local changes](../shadcn-customizations.md). The other bases remain stock.

Refreshed accordion, badge, button, card, dropdown-menu, popover and sheet from
the official live `new-york-v4` Radix registry. The registry now imports the
consolidated `radix-ui` package and uses React 19 component props, including refs.
No local visual or behavioral modifications remain inside these seven bases.

[The provenance manifest](shadcn-stock.json) records the exact fetched URLs,
upstream content SHA-256 digests, and installed source digests. Installation maps
`cn` to the repository's `@/lib/utils` and applies Biome formatting. Installed
digests normalize CRLF to LF so Git's line-ending conversion does not create
false drift. [The recorded upgrade diff](shadcn-2026-10-12.patch) compares the
previous Tailwind 3 stock bases with the installed Tailwind 4 versions.

The three previously approved fixes documented in
[the prior audit](shadcn-2026-10-11.md) remain above the stock bases:

- `FocusSafeAccordionContent` pads the animated content for outward focus rings.
- `StableDropdownSubTrigger` preserves submenu pointer focus.
- `LocalizedSheetContent` renders the localized close control and preserves refs.
  The new upstream `showCloseButton={false}` API replaces the old DOM manipulation
  and first-child CSS hiding, removing that obsolete compatibility mechanism.

Custom `lightweight-select` and `responsive-dialog` remain custom components;
their Radix imports now use `radix-ui`. Callers infer Button props directly from
the component because the current stock implementation has no `ButtonProps`
export. No compatibility type or re-export is retained.

Stock components contain upstream literal colors, including `text-white` and
`bg-black/50`. The UI invariant guard recognizes only digest-verified stock
sources; this does not add legacy debt allowances or exempt modified/custom UI.
